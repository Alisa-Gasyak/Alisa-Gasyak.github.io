# Text Analyzer — консольный анализатор текста на Python

## Выбранная методология

**Agile**

### Обоснование:
- Возможна быстрая обратная связь при тестировании на разных текстах
- Легко добавлять новые метрики анализа без перестройки всей программы
- Подходит для индивидуальной разработки

---

## Этапы работы по частям

### Этап 1 — Базовый анализатор
- Подсчёт символов (с пробелами / без)
- Подсчёт слов
- Подсчёт предложений
- Консольный ввод/вывод

### Этап 2 — Расширенная аналитика
- Частота слов
- Подсчёт 5 самых частых слов
- Средняя длина слова
- Индекс Флеша-Кинкейда (уровень сложности текста)

### Этап 3 — Качество и удобство
- Обработка ошибок (пустой текст, отсутствие файла)
- Загрузка из файла
- Форматированный вывод (таблица, секции)
- Документация и комментарии

---

## Применённые методы (по этапам)

| Этап | Методы | Применение |
|:---|:---|:---|
| 1 | **Анализ, синтез** | Разбивка текста на слова/предложения, сбор результатов в отчёт |
| 2 | **Индукция, моделирование** | Выявление частотных паттернов, индекс удобочитаемости |
| 3 | **Дедукция, эксперимент** | Иерархия ошибок, тестирование на разных входных данных |
