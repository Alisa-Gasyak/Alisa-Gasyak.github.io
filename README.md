# Text Analyzer — консольный анализатор текста на Python

## Выбранная методология

**Agile (Scrum-подход для одного разработчика)**

### Обоснование:
- Проект развивается итеративно (3 спринта)
- Требования не были жестко фиксированы — функциональность наращивалась постепенно
- Быстрая обратная связь при тестировании на разных текстах
- Легко добавлять новые метрики (частотность, индекс удобочитаемости)

---

## Этапы работы (по спринтам)

### Спринт 1 — Базовый анализатор
- Подсчёт символов (с пробелами / без)
- Подсчёт слов
- Подсчёт предложений
- Консольный ввод/вывод

### Спринт 2 — Расширенная аналитика
- Частота слов
- Топ-5 самых частых слов
- Средняя длина слова
- Индекс Флеша-Кинкейда (уровень сложности текста)

### Спринт 3 — Качество и удобство
- Обработка ошибок (пустой текст, отсутствие файла)
- Загрузка из файла
- Форматированный вывод (таблица, секции)
- Документация и комментарии

---

## Применённые методы (по этапам)

| Этап | Методы | Применение |
|:---|:---|:---|
| Спринт 1 | **Анализ, синтез** | Разбивка текста на слова/предложения, сбор результатов в отчёт |
| Спринт 2 | **Индукция, моделирование** | Выявление частотных паттернов, индекс удобочитаемости |
| Спринт 3 | **Дедукция, эксперимент** | Иерархия ошибок, тестирование на разных входных данных |

### Сквозные методы:
- **Абстрагирование** — функции `count_words()`, `top_words()` как независимые модули
- **Формализация** — перевод задачи в строгие типы данных Python
- **Сравнение** — сопоставление результатов на разных текстах
